# ชื่อโปรเจกต์ เว็บแอปพลิเคชันค้นหาฟอนต์จากภาพโดยใช้เทคโนโลยีปัญญาประดิษฐ์

เป็นระบบที่พัฒนาขึ้นโดยมีความสามารถในการค้นหาฟอนต์จากภาพ ระบบรองรับการค้นหาฟอนต์ทั้งภาษาไทยและภาษาอังกฤษทั้งสิ้น 51 ฟอนต์ โดยสามารถรับภาพที่ผู้ใช้งานอัปโหลดและวิเคราะห์ลักษณะของฟอนต์ในภาพผ่านโมเดลปัญญาประดิษฐ์ที่ได้รับการพัฒนาขึ้น จากนั้นแสดงรายการฟอนต์ที่มีความคล้ายคลึงกันพร้อมค่าเปอร์เซ็นต์ความคล้ายของแต่ละฟอนต์ เพื่อให้ผู้ใช้งานสามารถเปรียบเทียบได้อย่างชัดเจน
